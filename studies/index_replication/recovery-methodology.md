# 回本等待与持有期风险

本研究使用通过权威交易日历与报价完整性检查的供应商指数路径，不使用尚未通过估值审计的自制400股净值。
原始数据、全量买入日明细及输入哈希保存在仓库外；公开页面只展示派生统计。

```bash
uv run market-research report index-study --study studies/index_replication/recovery.study.json
```

## 定义

- **完整水下期**：此前高点至首次重新达到或超过该高点。自然日为两日期之差，交易日为两个观测位置之差（输入日历已校验）。相等价格即视作回本，不要求创新高。
- **当前水下期**：截至最后观测日仍未恢复的区间。recovery_date为空，censored=True；观察时长仅为下界，不能当作已完成恢复时长。
- **每个买入日的首次回本等待**：买入日之后首个不低于买入价格的观测日。一天后上涨即等待一个交易日；它不保证后来不会重新亏损。样本最后一天没有后续观测，也保留为删失记录。
- **固定持有期**：在买入日的1/3/5/10周年或之后首个交易日评价，周年超出样本末尾则未成熟。亏损比例的分母只包含成熟窗口，同时单列未成熟数量；不把未成熟当作盈利或零收益。
- **当前回本所需涨幅**：历史高点/当前点位−1，区别于当前回撤绝对值。例如下跌50%需要上涨100%。

最长已完成等待与最长已观察等待分别出表。不根据完成者平均恢复时间预测未来，不拟合未经验证的有限“理论最长回本时间”。
样本开始前的高点不可见，所有最长值只适用于列出的窗口。重复、空值、非正或非有限点位会阻断计算。
现金流价格指数和供应商税前全收益指数分组，不拿复权股价冒充独立验证的分红账本。
微盘采用供应商点位口径，分红规则待独立核验。所有结果均未计税费、通胀和机会成本。

## 产物

`recovery_summary.csv`、`recovery_episodes.csv`、`recovery_entries.csv`、`recovery_horizons.csv` 和 `recovery.html`。
主 `receipt.json` 记录输入哈希与日历证据；输入阻断时回本文件也重写为空并在页面显示原因，不保留旧成功净值。
网页入口为 `web/public/research/recovery.html`，由本地核验后的HTML派生报告生成，不包含原始价格和机器路径。

主站现在原生整合：`#cashflow`、`#microcap` 内有回本指标、指数选择、水下区间图、持有期统计和买入日等待明细；
`#overview` 按价格、税前全收益、微盘供应商点位分组比较。独立HTML只作为附件，不使用iframe。
模块展示完整样本，与旧收益图的短期窗口筛选独立；微盘旧版未通过估值审计的档案不参与新模块。

同一次研究运行额外输出 `recovery.json`：包含各指数的口径、样本区间、汇总、区间、持有期和最多20条最久买入日等待。
不含原始行情或本地路径；未成熟比例、未完成恢复日期保留JSON null。输入失败时同步清空JSON，保留阻断状态。
核验后将该文件复制至 `web/public/data/research/recovery.json`，与独立附件一同提交公开快照；浏览器不重新计算收益。

图表约定：按所选指数比较最长10段水下时长，并额外保留未完成区间；横向条形使用现有主站ECharts、零起点自然日轴、
蓝色单一色系，日期标签和表格明确区分已完成/尚未回本。表格保留交易日、谷底、区间回撤以便精确核对。
样本不足的持有期用N/A，不能绘成0%。桌面与390px手机窗口用真实浏览器校验；表格在自身容器横向滚动。

```bash
uv run --with playwright python web/scripts/check-recovery-ui.py http://127.0.0.1:4189/
```

## 首轮结果（2026-09-09）

现金流共同窗口2015-01-05至2026-09-04，微盘共同窗口2023-07-04至2026-08-14。

| 指数 | 最长已完成水下期（自然日） | 高点 | 回本 |
|---|---:|---|---|
| 800现金流（价格） | 1073 | 2018-02-05 | 2021-01-13 |
| 1000现金流（价格） | 2285 | 2015-06-12 | 2021-09-13 |
| 同花顺微盘 | 308 | 2024-01-04 | 2024-11-07 |

800价格指数中，持有1年成熟窗口的历史亏损比例约26.16%；持有5年仍有约1.35%的成熟窗口亏损。
这些窗口高度重叠，不是独立样本，不能称为未来亏损概率。首次回本和固定持有期结果是不同指标。
指数历史包含回溯构建，国证2024年规则修订、A500发布日期之前的历史都不能误当作当时真实可投资的表现。
这里只探索供应商指数时间风险；A500/1000本地成分复制、公司行为账本及微盘可执行策略仍需独立验证。
