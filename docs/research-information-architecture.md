# 研究信息架构

`market-research` 的公开入口按四类研究域组织：

1. 现金流策略探索：现金流、股息和调仓频率研究；
2. 小微盘策略探索：A 股小微盘规则重建，以及跨市场小微盘流动性 sub tab；
3. 市场长期风格研究：指数、ETF、Barra 和 18 年因子市场证据；
4. 跨市场探索：跨市场流动性、Global Six-Market、FX 和分散化研究。

“策略探索”是页面组织名称，不代表生产资格。alpha、IC、decay、signal
ranking 和策略选择仍属于 `quant-research`；通用回测、组合、风险、成本
和执行模拟仍属于 `quant-platform`。
